# Official submission and evidence checklist
Last checked: 2026-10-08.
Official site: https://scienceclawhack.ai/
Early application: https://scienceclawhack.ai/apply.html ; early deadline **October 16, 2026**. ScienceClaw event **October 30–November 1, 2026**. Organizers emphasize a meaningful science problem, a functioning decentralized collective, measured scientific/technical results and collaboration. Team limit 2–5 in application.
**Unconfirmed:** final hand-in portal, exact submission time, video duration, required public repo, slides format. Recheck the official website and organizer instructions before finalizing. Do not invent requirements.

## Recommended (not yet organizer-mandated) evidence package
- [ ] Completed official application and event registration status independently verified
- [ ] Actual scientific problem and falsifiable hypothesis, external domain expert input if available
- [ ] Runnable system plus clean-install reproduction
- [ ] Real research case, data/source license, code, run manifest, saved raw execution logs
- [ ] Blind commit → reveal → unexpected need → independently claimed experiment → verdict demo
- [ ] Controlled, matched-budget baselines and ablation study with failures and intervals
- [ ] Agent action/independence proof and independent reviewer approval records
- [ ] Third-party integration example and acknowledgement (only when actually achieved)
- [ ] Concise README, command, figures, short demo and fallback artifacts
- [ ] Official rubric self-audit and current verified final submission instructions

## Official rubric
Scientific/technical impact 25; collective capability 25; problem significance 20; decentralized agency 20; execution/validation 10; collaboration bonus up to 10.
