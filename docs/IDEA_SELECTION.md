# Competitive ideation decision — choose a falsifiable edge, not a generic agent product
Date 2026-10-08. We do not know what judges will award. Criteria come from https://scienceclawhack.ai/. All scores below are *qualitative prioritization*, not measured product performance or predicted judges' points.

## Candidate A: Generic decentralized hypothesis swarm
Origin: Hans's presentation slides 2, 6–7. Scientific appeal high, implementability medium, **novelty LOW** after AutoScientists (Gao et al., May 2026) which already has local teams, shared state and adaptive experiment selection. Reject as the complete differentiator; reuse as the organizing substrate.

## Candidate B: Pure blind RepliClaw replication firewall
Origin: existing repo. Execution maturity high; ability to prevent false consensus appealing. Weakness: current protocol centrally fulfills tasks, simple six-fixture "wins" are not real generalization and live LLM baseline tied. A standalone claim of decentralized novelty would fail skeptical judges. Keep evidence, traces and independent prediction commitments as trust mechanism.

## Candidate C: Evidence-Escrow Scientific Swarm for counterfactual AI failure diagnosis — PRIMARY
Combine Hans's evidence-adaptive local science with RepliClaw's independent escrow **and** controlled SimpleAudit interventions. Require testable cause-discriminating predictions *before* experiment, publish machine-verified observations *after*, measure who changed experiments and why. Scientific advantage is an **empirical question**, not already proven. Highest alignment with own tooling, compelling live demo, importance, and non-redundant gap vs AutoScientists and trajectory-only AgentRx. Condition: must show actual controlled causal intervention and match strong adaptive manager baseline.

## Candidate D: Universal agent auditing network / marketplace
Could earn collaboration credit, but generic infrastructure has weak direct scientific contribution and creates deadline/scope risk. Make a narrow, usable verify API as P11, not principal research novelty.

## Winner-selection criteria (non-numeric)
1. Can a judge **see a real falsifiable finding** and rerun it?
2. Is the decentralized component causal/observable, not theater?
3. Does the model need multiple independent capabilities to reach the finding?
4. Can we outperform or at least meaningfully compare with AutoScientists-inspired sharing and strong centrally adaptive manager under equal spend?
5. Can an external team use the verified findings/tool in 10 minutes?
6. Can we complete within 2026-10-16 application and Oct 30 event rather than build a research OS?
Only C satisfies the strategic combination well, subject to experiments.

## Hero moment judges should remember
*Agent A hypothesizes retrieval failure; Agent B suspects the judge. Both seal predictions. A controlled retrieval swap changes the target answer but leaves the judge verdict unchanged. Agent B independently changes its next experiment to audit the evaluator. A third agent executes a different controlled test and finds the evaluator was comparing against an outdated policy. The final report preserves both causes, machine outputs, pre-result forecasts, open alternatives, and a repeatable regression.*

This is **illustrative storyboarding**, NOT an observed finding; agents must be free to find something else. If actual tests support a different account, demo that. Avoid rehearsing expected behavior via hidden injected prompts.

## Research contribution framing
C1: prequential independent evidence-escrow protocol for an asynchronous investigator collective (combination rather than invented hash primitive).
C2: counterfactual experiments tied to audit/verification traces that *distinguish* competing failure hypotheses.
C3: **controlled empirical study** of local reallocation vs central adaptivity, free-sharing vs escrow, random/diversity vs greedy on honest AI failure attribution.
Minimal publishable contribution if no positive delta: a transparent benchmark/protocol for measuring false consensus and genuine independent agent reallocation, with clear limits.

## Kill switch
If working tests cannot show time-ordered commitments, an actual intervention, and local non-scripted choice by Oct 15, narrow from "swarm finds root cause" to a rigorously verified multi-agent AI-audit demonstration. Never invent a competitive advantage or submit made-up metrics.
