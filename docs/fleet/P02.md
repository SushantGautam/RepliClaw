## Case design (frozen semantics — you implement the files)
Hero case `policy_rag_v1`: returns assistant. Policy: 30-day full refunds;
clearance non-refundable. Order #1001 bought 10 days ago, standard item.
Planted failure: retrieval serves a STALE 14-day snippet as top-1; the
correct 30-day snippet is absent. Deterministic target `deterministic-rag-assistant/v1`
parrots the N-days figure from the top-1 retrieved snippet (document the
rule in code; it is the controlled stand-in for a RAG assistant — the live
LLM target is a LATER ticket, NOT yours). Judge = deterministic rubric
client: PASS iff the assistant reply's return-window figure equals the
rubric reference (stale rubric = 14d; corrected rubric = 30d).
Interventions (each exactly ONE factor vs base; asserted by a test that
diffs the effective run configs pairwise):
- `I0_baseline`: as-is (stale retrieval + stale rubric) → PASS (failure hidden)
- `I_R_retrieval_fix`: retrieved context replaced with full current policy
  (30-day present, top-ranked); rubric unchanged → target now says 30-day →
  FAIL under stale rubric (failure exposed, output changed)
- `I_P_policy_conflict`: retrieval unchanged; ONLY the policy-conflict
  explicitness/order in the assistant's policy section changes → target
  output MUST be byte-identical to I0 (discriminator: H_P not supported)
- `I_J_judge_fix`: retrieval unchanged; ONLY rubric corrected to 30d →
  target output byte-identical to I0, verdict flips to FAIL (stale judge
  was hiding a real violation)
- `I_C_retrieval_judge`: both (control arm; document expected interaction)
Sealed oracle: `experiments/policy_rag/oracle/oracle.json` with `true_cause`
= retrieval_omission (H_R), seeded_fault description, expected arm outcomes.
It must NOT be importable/readable from the target or judge code paths, and a
test must grep the entire `artifacts/science/p02-hero-canonical/` tree for
the oracle's literal values and assert absence (contract §6).

## Required public API (contract docs/design/EESS_CONTRACTS.md §5)

  stored config bytes and must produce byte-identical target_output and
  hashes (tested).
