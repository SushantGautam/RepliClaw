# F06 — Distributed Need-Dispatch Implementation (cross-process)

**Goal (G1):** Follow-up needs are claimed and fulfilled by independent worker PROCESSES
under cross-process atomic leases, instead of the central in-process
`protocol.py::_fulfill_need` dispatch. The in-process path remains as a comparison baseline.

**Contract source:** `docs/design/NEED_DISPATCH.md` (merged 2026-10-08) — the
implementation MUST match its §6.1 symbol contract and §7 adversarial spec,
plus the must-fix items below (from the F04 dual review).

**Depends on:** F04 (done), F02 (ExecutionRecord — `verify()` for executions must use
F02's verified-execution API once merged; if F02 is not yet merged when work starts,
work from the main-tree `tests/test_f02_execution.py` contract and flag the delta).

## Owned paths

## MUST-FIX items from the F04 dual review (incorporate, then mark resolved in handoff)
1. **open_needs closure:** `NeedBroker.open_needs` must exclude needs with a LIVE LEASE
   or a `need_fulfilled` event — intersect the index with broker state; do not merely
   wrap `iter_open_needs`.
2. **Eligibility field:** eligibility reads `NeedItem.preferred_skills` (there is no
   `preferred_methods` in the vendor schema). Reconcile the `method_family` vocabulary
   in the worker capability against `preferred_skills`; SPEC-3 asserts the same field.
3. **Real-subprocess spec (MAJOR):** at least one scenario spawns ≥2 child processes
   via `start_worker_pool` and asserts the atomic claim holds ACROSS OS PROCESS
   BOUNDARIES. A single-process `threading.Lock` fake must not satisfy SPEC-1/2/5.
4. **Need closure primitives:** Step-10 flow uses `broker.open_needs` /
   `broker.fulfilled_artifact` (a peer's `scan_needs` never closes a need).
5. **SPEC-6 frozen clock:** pin `score_need` equality to a frozen clock
   (monkeypatch `pressure._now_utc`); document the precondition in the test.
6. **Subprocess protocol:** spec the M8 wire format — `worker_factory` signature,
   JSON-over-stdout message schema, renew/heartbeat, completion/reap — in the handoff.
7. **Verification:** `fulfilled_artifact()` returns the VERIFIED artifact id
   (disambiguated from "first published"); mark verified inside
   `consume_fulfilments` or via explicit `mark_verified`; document who writes the
   index vs the `need_opened` event.
8. **TTL constants:** default `lease_ttl_s=120`, heartbeat renewal at `ttl/3`;
   keep configurable so F08 live runs can widen.
