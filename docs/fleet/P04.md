## Mission
Implement the decentralized task market where INDEPENDENT agents publish
unmet needs, self-rank valid actions with a local utility policy, and claim
work through an ATOMIC cross-process lease — with NO central allocator that
ranks scientific options or assigns questions. This is the G4 gate: "genuine
local agency: different worker claims need without central allocator;
evidence-injection replay changes agent choice and produces trace."

Design basis: `docs/design/NEED_DISPATCH.md` (merged F04 design, esp. §4
leases, §5 isolation, §6 symbol surface, §7 adversarial spec) — REUSE its
decisions (O_EXCL file locks, TTL, generation counter, capability self-declaration,
append-only broker log). The 8 F04 carry-overs in
`docs/checkpoints/CP-20261008-F04.md` §"F06 carry-over" are binding lessons:
esp. (1) open_needs must EXCLUDE leased/fulfilled needs, (2) eligibility field
naming consistency, (3) real-OS-subprocess atomicity test (threading.Lock fakes
are explicitly insufficient), (5) freeze the clock for deterministic ranking
tests, (8) disambiguate fulfilled winner (verified one) + writer of index vs event.

The v2 contract is FROZEN: `docs/design/EESS_CONTRACTS.md` §4 (Need + lease),
§2 (events: need_published, need_claimed, need_released, need_expired,
choice_ranked, choice_changed). Code to it.

## Required API (pydantic v2 / dataclasses; read `src/repliclaw/models.py` for style)
`src/repliclaw/needmarket/`:
- `broker.py`: `NeedBroker(root: Path, lease_ttl_s: float = 120.0, clock: Callable[[], float] = monotonic factory)`:
  * `publish(need: Need) -> str` (appends to `needs.jsonl` + `events.jsonl`)
  * `open_needs(exclude_agent: str) -> list[Need]` — EXCLUDES leased (live) and
    fulfilled/expired-cancelled needs (carry-over 1)
  * `claim(need_id, agent_id) -> Lease | None` — O_EXCL create of
    `locks/<need_id>.lock` (atomic cross-process; loser gets None; on expiry,
    winner atomically replaces with `generation+1`); writes `need_claimed` event
  * `renew(lease) -> bool`; `release(lease, reason)`; `expire_due()` (or
    lazy-on-access expiry — document choice); `fulfill(need_id, artifact_id,
    lease, verified: bool)` (only `verified=True` may mark done — carry-over 8;
    unverified fulfilment is an event, not a state change)
  * `claim_history(need_id) -> list[dict]` (audit)
  * crash recovery: process death leaves a stale lock → expiry → re-claim
    (tested with a killed subprocess)
- `needs.py`: `Need` (contract §4 schema `repliclaw.need/v1`),
  `WorkerCapability` (agent_id, producible_types, method_family, model,
  budget_tokens/budget_wall_s), `eligible(need, capability) -> bool`
  (pure self-check; no pre-assignment)
- `policy.py`: `ActionPolicy` protocol:
  `rank(agent_id, needs: list[Need], evidence_snapshot_sha: str, rng_seed: int) -> list[RankedAction]`
  where `RankedAction {need_id, utility: float, components: dict, reason: str}`
  (reason MUST cite the evidence/observation or capability gap that drove the
  score — this is the T4 trace). Implement:
  * `LocalEigPolicy` — transparent heuristic:
    `U = est_info_gain(need, agent, snapshot) / est_cost(need)
         + lam * diversity_bonus - mu * crowding_penalty`,
    `est_info_gain` from a caller-supplied `discriminability` mapping
    (need_id → dict[hypothesis_id, float]) — the POLICY does not see the oracle;
    P07 feeds real numbers; tests use fixtures. `lam`/`mu` per-agent config.
  * `RandomPolicy` (rng_seed-pinned) — the mandatory cheap comparator
  * `GreedySharedPolicy` (agent-agnostic global score: same ranking for all
    agents given same snapshot — the anti-pattern comparator)
  * Determinism: same (needs, snapshot, agent config, rng_seed) → same
    ranking (frozen clock + pinned seed; carry-over 5)
- `worker.py`: `NeedWorker(capability, broker, policy, execute: Callable[[Need], dict], ...)`:
  `cycle() -> result|None`: open_needs → eligible → policy.rank → claim →
  execute (blind callback) → fulfill(verified=callback-returned flag) → events
  (`choice_ranked` with full components BEFORE claim; if this cycle's ranking
  differs from the agent's previous ranking for the same snapshot key, emit
  `choice_changed` with {prev_ranking, new_ranking, snapshot_sha, delta_reason})
  `run(max_cycles)`.
- `replay.py`: `snapshot(evidence) -> str` (content-addressed sha256 of
  canonical evidence dump), and helper to rebuild a broker state from an
  events replay (for P07's counterfactual replay).

## Red tests to write FIRST (then make green)
1. `test_atomic_claim_two_processes` (REAL subprocesses, carry-over 3):
   2 OS processes both attempt claim on the same need concurrently (use
   `subprocess` + barrier file; NO threading.Lock as the mechanism under test)
   → exactly one wins; loser's event present; no partial lock files.
2. `test_lease_expiry_reclaim`: claim with ttl=0.5s, wait, second agent
   reclaims with generation+1; history shows both; no double-fulfil.
3. `test_crash_recovery`: claimer subprocess killed (SIGKILL) after claim →
   expiry → other agent fulfils; broker log consistent.
4. `test_no_central_ranking`: broker exposes NO method that returns a ranked
   list of needs (assert via inspection: only per-agent policy ranks); broker
   API cannot be used to "assign" (claim requires an agent).
5. `test_evidence_changes_choice` (T4): agent ranks with snapshot A →
   claim/none; publish new evidence → snapshot B (different sha); same agent
   same policy same seed ranks differently → `choice_changed` event present
   with delta_reason citing the changed observation; assertion is on the
   OBSERVED difference (no hard-coded "agent must pick X").
6. `test_policy_determinism`: LocalEigPolicy + RandomPolicy + GreedyShared
   all deterministic under pinned seed/clock; GreedyShared produces
   identical ranking for two different agents (the comparator property).
7. `test_open_needs_excludes_leased_fulfilled` (carry-over 1).
8. `test_budget_enforced`: broker rejects claim beyond agent's
   budget_tokens when need.cost_estimate exceeds remaining budget (enforcement
   without ranking).
