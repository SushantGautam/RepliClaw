## Failure Analysis

### D-E failures (2/20 = 10%)

Both on **RCA-P-05** (`re2ob_checkoutservice_delay_1`), both seeds:
- Status: `aborted_budget` (envelope exhausted during phase-2 consult loop)
- Phase-1 completed successfully (all 3 investigators committed)
- Phase-2 ran out of token budget before completing
- Escrow shows phase-1 entries revealed, phase-2 entries unrevealed
- **Root cause:** This case has complex delay propagation across services;
  the 3 concurrent investigators + phase-2 consult exceeds 150K tokens

### C-EQ failures (4/20 = 20%)

All 4 are `UnknownServiceError: 'api-gateway'`:
- Cases: RCA-P-07 (`emailservice_delay`) × 2 seeds, RCA-P-10 (`cartservice_f1`) × 2 seeds
- Systematic (both seeds affected) → model hallucination pattern
- LLM invents 'api-gateway' which isn't in the service list
- Caught by sandbox validation (instrument working as designed)
- **Root cause:** Qwen3.8-27B occasionally hallucinates a plausible-sounding
  service name not present in the provided topology

## Mechanism Observations

1. **Concurrent execution works:** D-E phase-1 wall time (15-19s) ≈ single
   investigator time, confirming true parallelism (vs ~45s sequential).
2. **Deadline fallback never triggered:** All D-E phase-1 commits within 120s
   deadline. The `DE_INVESTIGATOR_DEADLINE_S=120` was generous for these cases.
3. **Escrow integrity maintained:** All escrow files show proper commit→reveal
   sequencing with SHA256 hashes. Phase-2 entries remain unrevealed (correct).
4. **Committee adjudication functional:** D-E committee produced final rankings
   consistent with phase-1 evidence in all completed runs.
5. **C-EQ speed advantage:** Centralized planner completes in ~11s vs D-E's
   ~21s — expected since it uses fewer total LLM calls (1 agent vs 3+committee).

## Limitations

1. **No holdout claim:** Cases are historically exposed (R8/R9). This is
   exploratory revalidation only.
2. **Token counts not persisted:** The V4 instrument tracks tokens in-memory
   via LLMToolSession but doesn't include them in the result object. Wall time
   serves as a proxy. (Fix: add `total_tokens` to `_result()`.)
3. **Small n:** 20 pairs limits statistical power. The 15pp point estimate
   has a wide CI [−5%, +35%].
4. **Single model:** Qwen3.8-27B only. The 'api-gateway' hallucination may be
   model-specific.
5. **Ablations not run:** The no-consult and no-committee ablation conditions
   were not included in this run (require separate invocation).

---

## Verdict (per Comparison Plan §10 Decision Gate)

**Result: NULL / INCONCLUSIVE**

The point estimate favors D-E (+15pp top-1), but the 95% CI includes zero
and the p-value is 0.555. With n=20 pairs, we cannot distinguish a real
advantage from noise. The experiment is scientifically valid (fair access,
same envelope, same model, deterministic scoring) but underpowered.

**Next steps to resolve:**
1. Obtain fresh holdout case data (RE2/RE3 non-frozen cases) for a proper
   prospective evaluation
2. Increase n: 16 fresh cases × 2 seeds = 32 pairs would give ~80% power
   to detect a 15pp effect
3. Fix token persistence in the instrument
4. Run ablations to decompose the contribution of consultation vs committee

## Ablation Results (4 cases × 2 seeds, n=8 per condition)

Run on a diverse subset: adservice_cpu (easy), cartservice_delay (medium),
checkoutservice_delay (hard), productcatalogservice_delay (hard).

| Condition | N | OK | Top-1 | Top-5 | Avg Tokens | Avg Wall | Crashes |
|-----------|:-:|:-:|:-----:|:-----:|----------:|--------:|:-------:|
| D-E-full | 8 | 7 | 4/7 | 7/7 | 121,058 | 32.8s | 1 |
| D-E-no-consult | 8 | 8 | 4/8 | 8/8 | 99,946 | 23.0s | 0 |
| D-E-no-committee | 8 | 8 | 4/8 | 8/8 | 113,830 | 26.9s | 0 |
| C-EQ | 8 | 8 | **6/8** | 8/8 | **56,718** | **16.7s** | 0 |

### Mechanism attribution:

1. **Consultation (phase-2 commit-reveal):** Costs ~21K tokens and ~9s wall time
   but contributes **zero** additional top-1 accuracy (4 hits in both full and
   no-consult conditions; the same 4 cases are hit). The mechanism adds cost
   without measurable diagnostic value on this case set.

2. **Committee sandbox (fresh LLM round):** Costs ~14K tokens and ~4s wall time
   but also contributes **zero** additional top-1 accuracy (4/8 in both
   full and no-committee conditions). The deterministic adjudication ranking
   is already optimal given the phase-1 evidence.

3. **C-EQ dominance on hard cases:** On `productcatalogservice_delay`, C-EQ
   achieves 2/2 top-1 while ALL D-E variants (full, no-consult, no-committee)
   score 0/2. The centralized planner's sequential reasoning over the full
   telemetry appears better suited to ambiguous delay-propagation cases where
   parallel investigators converge on the same wrong hypothesis (checkoutservice).

4. **Token efficiency:** C-EQ uses **half** the tokens of D-E-full (57K vs 121K)
   and completes in half the wall time (17s vs 33s). The decentralized overhead
   (3× investigator prompts + consultation + committee) is substantial.

### Interpretation:

The ablation data suggests that on this task distribution (RCAEval telemetry
diagnosis), the mechanisms that define decentralization (parallel investigation,
escrowed consultation, committee adjudication) add cost without adding accuracy.
The centralized adaptive manager matches or exceeds the decentralized arm on
top-1 while using fewer resources. This is a **negative result for the
decentralization hypothesis** on this benchmark, consistent with the null
finding from the full run.

**Caveat:** n=8 per condition limits power. The 2pp difference (4/8 vs 6/8)
is not significant. A definitive conclusion requires the fresh holdout set
with adequate n.
